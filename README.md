# AdVision

Личный кабинет для видеонаблюдения с рекламными трансляциями на мониторах/ТВ.

Стек: React + TypeScript, MobX, React Router, Webpack. Сейчас всё работает на моковых данных (без бэкенда).

## Запуск

```bash
npm install
npm start
```

Откроется http://localhost:3000. Вход — любой email и пароль от 4 символов (мок-авторизация, токен хранится в localStorage).

## Структура

- `src/stores` — MobX-хранилища: `AuthStore`, `CameraStore`, `AdStore`, `MonitorStore`.
- `src/mock` — стартовые моковые данные и генератор SVG-заглушек для рекламы.
- `src/components/VideoPlayer` — плеер трансляции. Ссылка на камеру ожидается в формате go2rtc
  (`http://host:1984/stream.html?src=NAME`) и встраивается через `<iframe>`, когда сервер go2rtc
  доступен. Пока реального сервера нет, показывается анимированная заглушка — переключается кнопкой
  «Подключиться к go2rtc» / «Показать заглушку».
- `src/pages/Cameras` — список камер, добавление ссылки на трансляцию, привязка рекламы.
- `src/pages/Ads` — управление рекламными роликами (мок: генерируются как SVG-баннеры).
- `src/pages/Monitors` — мониторы/ТВ с привязкой камеры и рекламы.
- `src/pages/Display` — публичная страница вида `/display/:monitorId`, которую открывает сам монитор/ТВ
  (без авторизации) — показывает камеру и ротацию рекламы.

## Дальнейшие шаги (не сделано в этой итерации)

- Подключение реального бэкенда и API вместо мок-хранилищ.
- Полноценный go2rtc WebRTC/MSE клиент вместо `<iframe src="stream.html">` (см. `VideoPlayer`).
- Загрузка изображений/видео для рекламы вместо генерируемых заглушек.
